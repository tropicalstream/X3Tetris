DROP YOUR LEVEL MUSIC HERE (MP3)

Any filenames work — tracks are sorted alphabetically and mapped to levels
in order (track 1 = level 1, track 2 = level 2, ...). The last track carries
all higher levels. Suggested naming:

    level01.mp3
    level02.mp3
    level03.mp3
    ...

Each track loops until you level up, then the next one takes over —
the Tetris Effect idea: the game IS the music. MP3s are gitignored,
so your library stays yours.
